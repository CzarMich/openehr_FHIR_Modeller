      USER GUIDE
      
                        
      How to use your workspace
      
                        
      
                            Start with a question or a source document, develop a draft, then review and save your work.
                            You can return to Chat at any time without losing the message you are writing.
                        
      
                    
      
                    
      
                        
      Check models and run AQL
      
                        
        
                            
      1. 
                                Open the settings gear and expand CDR Connections. Add your server
                                address and the authentication details supplied by your organisation. Press
                                Save connection, then Test.
                            
        2. 
                            
      2. Open AQL workspace. Choose the CDR environment you want to query.
        3. 
                            
      3. 
                                Expand Model paths and template validation to load a model from your
                                repository, your computer or the selected CDR. Repository templates load their saved
                                archetypes automatically. For local templates, select their archetype files too.
                            
        4. 
                            
      4. 
                                Press Inspect paths. Select the fields you need and press
                                Generate query. You can also describe the result you need and press
                                Ask assistant to write AQL. Both actions fill the same AQL query box;
                                review the draft and enter any parameter values before running it.
                                Clear selection clears all selected fields, including ones hidden by
                                the filter, and keeps your query text. In the editor, type the root alias followed by /
                                to choose a path from the inspected model. Use Validate to check syntax
                                and the selected template's paths. An incomplete check tells you what still needs
                                review.
                            
        5. 
                            
      5. 
                                Press Run query. View the returned rows as a table, JSON or the raw
                                response. Use Cancel query to stop waiting. The CDR may continue
                                processing a request after cancellation.
                            
        6. 
                        
      
                        
      
                            Formatting, inspection and validation do not need an AI connection. Query execution needs a
                            CDR connection with permission to read data. Only you can run a query; the AI assistant
                            cannot execute it, see its results or read your query history and saved queries. Do not
                            paste patient information into chat. A valid path does not prove that a query is clinically
                            appropriate or supported by every CDR.
                        
      
                        
      
                            Saved queries and history contain query text, not results. Keep patient identifiers in
                            parameters instead of query text. Results are cleared when you sign out or reload; use Copy
                            or Export only when you want a local copy. Each CDR environment has its own query library
                            within your profile, even with a centrally configured server. Use
                            Show my unassigned queries
                            for older queries; load and save one to copy it into the selected environment.
                        
      
                        
      Why the assistant cannot see CDR patient data
      
                        
      
                            The assistant has no tool that can execute a CDR query or read results, history or saved
                            queries. Those requests are rejected by the server, even if an assistant tries to make them.
                            Only an authenticated request from the workspace can return results to your screen.
                            Credentials stay on the server, and result rows and parameter values are not stored in chat
                            or query history.
                        
      
                        
      
                            When you ask for AQL, a separate drafting session receives only the model's fields and your
                            instruction. It cannot read the query already in the editor. This keeps identifiable records
                            out of the AI provider while still allowing help with model structure. Automated tests check
                            blocked execution, separate users and synthetic private values. Content you deliberately
                            type into an instruction, upload or include in a model is still shared for that task: keep
                            it free of identifiable patient information.
                        
      
                        
      Use a template in a form tool
      
                        
      
                            Load the OET and its archetypes, then press Inspect paths.
                            Download compiled template provides the OPT;
                            Download Web Template
                            provides the form schema when available. Choose the format your form tool accepts. An OET
                            needs its archetypes; it is not a self-contained form schema. Repository template saves
                            include compiled outputs in separate folders, with a manifest linking the exact files. A
                            successful form-schema check does not replace clinical review or guarantee every designer's
                            import support.
                        
      
                        
      
                            Each request returns at most 1,000 rows and has a maximum two-minute CDR timeout. To page
                            through results, remove LIMIT/OFFSET from the query and use Page size, Offset and Next page.
                            Add ORDER BY when stable ordering matters.

      Accounts and shared connections
      
                        
      
                            Choose Sign in at the top right. The account window includes sign-in,
                            account creation and recovery. When setting up your authenticator, choose Add account in the
                            app on your phone and scan the QR code. Enter the six-digit code here, then save your
                            recovery codes somewhere private. On the same phone, use Open authenticator app. If scanning
                            is unavailable, expand Can’t scan? Enter the key manually.
                        
      
                        
      
                            The first platform owner completes setup before anyone can create an account. New accounts
                            require an authenticator and receive recovery codes. Keep the codes somewhere safe outside
                            the workspace. Five failed sign-ins lock password access; use a recovery code or ask your
                            administrator for a one-time recovery link. No email is sent.
                        
      
                        
      
                            Your chats and private connections belong to you. In Accounts, the platform
                            owner can open or close registration, assign roles and grant permission to use or manage
                            shared connections. Other administrators can manage ordinary users; they cannot take over
                            the owner account.
                        
      
                        
      
                            In the settings gear, authorised managers can select Shared workspace to
                            configure an AI connection or repository for permitted users. Shared Codex requires an
                            OpenAI project API key; Claude requires an API key; Copilot Studio uses your published
                            agent. Private connections are used first. Shared provider usage is billed to the configured
                            account. Files saved to a shared repository are visible to others with repository access.
                        
      
                        
      
                            The assistant has up to 20 minutes of working time per response. Time
                            waiting for your choices or save confirmation is excluded. If interrupted, use
                            Continue from saved progress below the response to reuse saved drafts.

      3.

      4.

                            Use selected options. Choose Write another answer for your

      Organise your chats
      
                        
      
                            Select Create project in the sidebar to group chats in a private folder.
                            Open a project's heading to see its conversations, or select + Chat to
                            start one inside it. Use the arrow beside a chat to move it to a project. You can rename a
                            project; deleting it keeps its conversations in Unfiled chats. On phones,
                            select Toggle conversations to see these controls. Moving a chat adopts the
                            project repository and folder, with a preview for existing artefacts. Messages and uploads
                            stay in the workspace. Project Settings lets you choose a default
                            repository and folder for new chats. The project name suggests a folder such as
                            Renal-care; you can choose a different path. Renaming or deleting a chat
                            project does not move or delete repository files.
                        
      
                        
      
                            Select × (Delete conversation) beside a chat to delete its messages and
                            uploaded files. You will be asked to confirm. Other chats and the project are kept.
                        
      
                    
      
                    
      
                        
      2. Upload documents
      
                        
        
                            
      1. 
                                In Chat, select the + button (Add files and images)
                                inside the message box. You can also drop files onto the box or paste a PNG/JPG image
                                while writing. You can select several PDFs and spreadsheets together.
                            
        2. 
                            
      2. 
                                Each file appears as a card. Text ready means text was extracted;
                                Image ready means the assistant can view the image.
                                Partly read or Needs attention includes an
                                explanation. You can keep typing while files upload.
                            
        3. 
                            
      3. 
                                Ask the assistant to read the files, summarise the requirements, and use them to prepare
                                a draft. Ask it to identify missing or conflicting information before modelling.
                            
        4. 
                        
      
                        
      
                            Text PDFs, Excel and OpenDocument spreadsheets, Word documents (DOCX), CSV, JSON, XML and
                            plain text can be read. Other formats can be attached, but may need conversion before their
                            contents can be used. PNG and JPG images can be interpreted by your selected assistant. For
                            a scanned PDF, attach the relevant pages as PNG/JPG images or provide a text version.
                        
      
                        
      
                            Select an image thumbnail to preview it, or × to remove an attachment before sending. Sent
                            files appear beside your message and remain available under
                            Files in this chat, where you can remove them from future responses. Use a
                            clear crop for small print. Image interpretation can miss details; check extracted clinical
                            information against the original before using it in a model.
                        
      
                        
      
                            PNG/JPG images must be single-frame and no larger than 20 megapixels. A
                            prepared copy up to 2048 pixels per side is sent to the assistant; the original is kept.
                        
      
                        
      
                            Each file can be up to 10 MiB. A conversation can hold
                            10 files, up to 30 MiB in total. Very long documents may
                            be shortened during extraction. Select a filename to download the original, or use its
                            remove button to detach it.
                        
      
                        
      
                            Only upload information you are allowed to use with your chosen AI provider. Attached images
                            and source excerpts may be sent to that provider when you send a message.
                        
      
                        
      
                            After attaching a publication, try: “Read this publication. Extract the assessment findings,
                            tests and follow-up information it describes. Show the sources and uncertainties, then
                            propose reusable archetypes and a draft template.”
                        
      
                    
      
                    
      
                        
      3. Add sources and repositories
      
                        
      
                            Open the Chat settings gear, then
                            My sources and repositories. Give each connection a name you recognise.
                            Your personal connections are available only to your profile.
                        
      
                        
      Add a CKM
      
                        
      
                            A CKM is a library of reusable archetypes and templates. Choose CKM, enter
                            its HTTPS service address, and select Save connection. Ask the CKM owner
                            for the service address and an access token if required. If your organisation already
                            provides the same CKM, it stays available and no duplicate is added.
                        
      
                        
      Add your Git repository
      
                        
        
                            
      1. Choose GitHub repository or GitLab repository.
        2. 
                            
      2. 
                                Enter the repository's HTTPS URL, such as
                                https://github.com/your-name/your-models, and the target branch, such as
                                main.
                            
        3. 
                            
      3. 
                                To save files, enter a personal access token with write access to that repository.
                                Public repositories can be read without a token. Your organisation may need to approve
                                access.
                            
        4. 
                            
      4. 
                                Select Save connection, then choose it under
                                Save artifacts to and press
                                Save repository selection for this conversation. Wait for
                                Active and check its URL, branch and folder.
                            
        5. 
                        
      
                        
      
                            You need permission to use the repository and branch. For an existing repository, choose a
                            branch that already exists. Removing a personal connection does not delete files from the
                            repository.
                        
      
                        
      
                            For GitHub saves, create a fine-grained personal access token limited to your repository
                            with Contents: Read and write. Paste it only in the connection form. To add
                            or replace a token later, select Update access beside the connection, enter
                            the token and select Save connection. Your active selection is kept.
                        
      
                        
      
                            Being the repository owner does not give every token write access. If GitHub refuses the
                            token, open
                            GitHub token settings, select the token and repository, and enable Contents: Read and write.
                            Back here, choose Update access and Save connection before
                            retrying. Leave the token field blank if you changed the existing token's permissions; enter
                            a token only when replacing it. A protected branch may require a separate draft branch.
                        
      
                    
      
                    
      
                        
      Choose where artefacts are saved
      
                        
        
                            
      1. 
                                Open the Chat settings gear, then choose your repository under
                                Save artifacts to.
                            
        2. 
                            
      2. 
                                Enter a Repository folder, such as AKI or
                                Clinical/AKI, or choose Use project folder. Leave it empty
                                to use the repository root.
                            
        3. 
                            
      3. 
                                Press Save repository selection. New chats remember this choice; chats
                                in a project use that project's defaults. Existing chats keep their own destination.
                            
        4. 
                            
      4. 
                                Ask the assistant to save the draft. Check the repository, branch, complete file path
                                and content in the confirmation before approving.
                            
        5. 
                        
      
                        
      
                            For example, the assistant can save a draft at
                            AKI/templates/oet/AKI_clinical_documentation.oet. The folders appear in GitHub
                            or GitLab when the first file is committed. Empty folders do not need a separate creation
                            step.
                        
      
                        
      
                            Saving a destination in a project also updates its defaults for future chats. To change only
                            the defaults, use the project's Settings. Moving a chat between projects
                            adopts the new project's repository and folder. Review the proposed paths, then press
                            Move chat and artefacts. Existing artefacts move in one commit within the
                            same repository and branch. A conflicting filename or changed revision stops the move.
                            Conversations and uploads remain in your workspace; only artefacts go to Git.
                        
      
                        
      
                            Keep model types in their own subfolders: archetypes/,
                            templates/oet/ and templates/opt/. For example, an AKI project can
                            contain AKI/archetypes/ alongside AKI/templates/oet/. Moving a
                            chat organises its saved models into these folders.
                        
      
                        
      
                            Saving an OET template also saves the exact archetypes it uses in
                            archetypes/, together in one commit. The confirmation lists every file. A
                            dependency manifest under data/json/template-packages/ links the template to
                            its exact archetype versions and records their file hashes. Changed archetypes update the
                            same filenames; older templates retain their original dependency versions. Missing or
                            unverifiable dependencies stop the save. When moving a chat, shared archetypes are copied
                            into the new project so other templates keep working. Import the template together with its
                            archetypes into your modelling tool.
                        
      
                        
      
                            Depending on your task, the assistant can also prepare queries, example data, terminology
                            tables, design notes and reports. Each supported file type has its own folder:
                        
      
                        
      
                            
                                
      
                                    Supporting files
                                    Project subfolder
                                
      
                                  
                            
                                
      
                                    AQL queries
                                    queries/
                                
      
                                
      
                                    JSON data and metadata
                                    data/json/
                                
      
                                
      
                                    Other XML
                                    data/xml/
                                
      
                                
      
                                    CSV tables
                                    data/csv/
                                
      
                                
      
                                    Markdown notes and reports
                                    documents/markdown/
                                
      
                                
      
                                    Plain text
                                    documents/text/
                                
      
                                
      
                                    YAML configuration
                                    config/yaml/
                                
      
                                  
                        
      
                        
      
                            Open Saved artefacts above your message box to find committed files. Choose
                            Open file, Copy path or Copy link. When
                            available, Saved version and Copy version link reference
                            the exact saved revision. Version history opens previous revisions; the
                            saved SHA-256 fingerprint identifies the file's contents. The file list updates after a
                            project move. Existing links inside documents are not rewritten when files move.
                        
      
                        
      
                            Versioning is automatic. Save an updated template or archetype using the
                            same filename. Changed contents create a new Git revision and become the current file;
                            previous versions remain in history. Saving identical contents makes no extra version.
                            Generated OPTs and form schemas also keep stable filenames. You do not need to add a date or
                            hash to the name. A new file revision stays a draft and does not automatically change its
                            openEHR identifier or carry over clinical approval.
                        
      
                        
      
                            Edited models stay yours. Template builds use archetypes from your selected
                            project's repository, including edits made in a designer. Ask to regenerate an existing
                            template to update the same OET file and its compiled outputs. Earlier files remain in Git
                            history. A newer CKM release is a separate upgrade: ask the assistant to compare it with
                            your edits before applying it. A changed fingerprint alone is not proof of a newer release
                            or clinical approval.
                        
      
                        
      
                            For older saved files, open Include older saved artefacts in the move
                            dialog and enter their repository paths, one per line. Files are never guessed from chat
                            messages. Choose Unfiled chats to remove the grouping while keeping the
                            current repository location.
                        
      
                        
      
                            If saving is unavailable, check that the intended repository is Active and
                            that its connection has a token with write access. An earlier message saying a tool was
                            unavailable does not describe the current connection.

      2. 
                                Ask the assistant to prepare and save the draft. For a personal repository, include a
                                relative file path, such as templates/oet/assessment.oet.
                            
        3. 
                            
      3. 
                                Read the proposed destination, file and changes in the confirmation. Select
                                Confirm save when they are correct, or cancel.
                            
        4. 
                        
      
                        
      
                            A save only happens after confirmation. If someone has changed the file, ask the assistant
                            to read the latest version and prepare the change again. Saving a model keeps it as a draft;
                            it does not approve it for clinical use.
                        
      
                        
      
                            If the assistant reports no personal repository, select your connection in this
                            conversation, press Save repository selection and retry. If another tab
                            changed the destination, your unsent instructions are kept so you can check the current
                            choice before sending again.
                        
      
                    
      
                    
      
                        
      5. Find and review models

                            inspect its source. Use Download source for a copy, or
                            Discuss in chat to ask about that version. To explore a personal
                            repository, ask the assistant in Chat.
                        
      
                        
      
                            Open Governance to inspect enterprise model reviews and validation
                            results. The actions you can take depend on your assigned role. Check the exact version and
                            evidence before recording a decision. Generated models need qualified review before clinical
                            use.

      7. Solve a problem
      
                        
      
                            
      I cannot send a message.
      
                            
      
                                Check that you are signed in and your selected assistant is connected under
                                AI connections. If chat is unavailable for this workspace, contact your
                                administrator.
                            
      
                            
      My file says unsupported or failed.
      
                            
      
                                Read the message beside it. Try a text-based PDF, DOCX, CSV or plain-text version. For a
                                scanned publication, attach the relevant pages as PNG/JPG images or extract its text
                                first. Reattach images uploaded before image support was available. Split files that
                                exceed the size limit.
                            
      
                            
      My upload timed out or the connection was interrupted.
      
                            
      
                                Keep the page open while the file uploads, then try adding it again if needed. If the
                                response was incomplete, reopen this chat and check its files before retrying. Your
                                unsent instructions stay in the message box.
                            
      
                            
      The response stopped or I lost my connection.
      
                            
      
                                Reopen the conversation to follow work still running on the server. If it has stopped,
                                choose Continue from saved progress. The assistant can reuse retained
                                drafts and completed source checks. Download retained files from
                                Artefacts and recovered drafts. A retained draft is not a confirmed Git
                                save: check the destination before retrying, and confirm the proposed save.
                            
      
                            
      I keep getting signed out.
      
                            
      
                                Active work renews your workspace session. After an hour without activity, or an
                                eight-hour workday, sign in again and reopen your conversation. Your saved progress
                                remains. Sensitive CDR and review actions may ask for a more recent sign-in.
                            
      
                            
      My repository refuses a save.
      
                            
      
                                Check the repository URL, branch and token permissions. If the token has expired, remove
                                the connection and add it again with a current token. Protected branches may require a
                                different branch. Your administrator must also enable saving for this workspace.
                            
      
                            
      A shared link does not open.
      
                            
      
                                Sign in to the same workspace. If the link has expired or been revoked, ask the owner
                                for a new link.
                            
      
                            
      I use Microsoft Copilot Studio.
      
                            
      
                                Your organisation can connect its Copilot Studio agent to the modelling server. Ask your
                                administrator for access and setup details. The Assistant selector in this browser
                                supports Codex, Claude and published Copilot Studio agents. See the Copilot Studio
                                browser setup above.
                            
      
                        
      
                        
      
                            If you need help from your administrator, share the error message and what you were trying
                            to do. Keep passwords and access tokens private.
