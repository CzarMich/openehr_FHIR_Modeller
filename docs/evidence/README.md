# Verification evidence

## Historical runtime evidence

Superseded runtime reports are retained in the [immutable historical evidence archive](https://github.com/CzarMich/openehr_FHIR_Modeller/tree/59c99e3/docs/evidence). They are not current C# test/deployment results. New acceptance artifacts must identify the exact revision, synthetic/live scope and limitations; never rewrite an old result to describe a replacement runtime.
